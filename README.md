# Shoot'Em UP

## What's is ? 
Here is my shoot 'em up, created by CHABOT Etienne and me, SOULIER Alex.  
  
A shoot 'em up is a genre of video game derived from action games in which the player controls a vehicle or character that must destroy a large number of enemies using projectiles as they progress through the levels, while dodging enemy projectiles to stay alive.

## How it works ? 

You play a small ship that fires missiles. The goal is simple: kill all the enemies and the boss (if there is one) while staying alive.  
You can make your own level by use the txt file in the file "Level".  
  
In the orderLevel.txt, you choose the order of the level.  
1  
2  
Or  
2  
1  
  
For levels, you choose this things :  
number of enemy bomb  
number of enemy shooter  
number of enemy shooter V2  
number of boss   
  
## How to win ? 
If you choose to have boss, you just need to kill the boss.  
Else, you need to kill every ennemies in the game.  
Good luck !

## Feature
- The boss have pattern (not finish).
- Heal spawn randomly in the game.
- You have Menu screen, Pause screen (escape), Victory screen and GameOver screen. You can restart when you win or die by returning to the menu.
